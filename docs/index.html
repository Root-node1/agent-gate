Overview

AgentGate is a deterministic spending firewall. AI agents submit spend requests; a pure-Python rule engine decides allow, deny, or needs human approval. Approved payments execute through PayPal (planned), and every decision is written to a tamper-evident, hash-chained audit log.

Documentation scope

This documentation covers the pre-deployment audit and the integration plan that follows it. Audit Markdown files in docs/ have been migrated to canonical HTML equivalents. Machine-readable files (Postman collection, GitHub Actions workflows, application configuration) remain in their native formats.

Architecture diagram


  AI agent  -->  AgentGate API (Django + DRF)  -->  PayPal (sandbox — planned)
                     |
                     +--> Rule engine (budgets, caps, merchant lists, thresholds)
                     +--> Injection screening (deterministic phrases, NFKC)
                     +--> Approval queue (human in the React dashboard)
                     +--> Audit log (append-only, hash-chained, DB trigger)
                     +--> Gemini chatbot proxy (planned, read-only advisory)
                     +--> Auth: email/password + GitHub OAuth + TOTP 2FA (planned)

  Dashboard (React 19 + TypeScript + Vite) <--> Session auth (Django)
                                                            <--> GitHub OAuth (django-allauth, planned)
                                                            <--> TOTP 2FA (django-two-factor-auth, planned)

  Deployment: Contabo VPS --> Caddy (HTTPS) --> Gunicorn --> Neon PostgreSQL

  Agent API:  Authorization: Bearer agk_... (constant-time hash compare)
  Dashboard:  Session cookie (CSRF-protected, role-based, 2FA-enforced for admin/approver)
  Chatbot:    Dashboard session cookie (CSRF-protected, server-side Gemini key)
