Scope

This audit covers the AgentGate codebase as of the audit/agentgate-predeployment-readiness branch (2026-10-27). It assesses the backend Django/DRF application, the frontend React dashboard (current state and planned integration), and the deployment environment requirements. It does not cover the Gemini chatbot integration (see Gemini Chatbot Integration) or the authentication implementation (see Authentication Architecture), which are not yet implemented.

Threat model

High-value assets

  1. Agent API keys — stored as SHA-256 hashes with prefix indexing; raw keys are never persisted.
  2. PayPal credentials — PAYPAL_CLIENT_ID / PAYPAL_CLIENT_SECRET in .env (planned).
  3. Gemini API key — planned to live in backend/.env only (never in frontend).
  4. Django secret key — DJANGO_SECRET_KEY in .env.
  5. Audit log — tamper-evident hash chain; head hash not anchored externally.
  6. Database — PostgreSQL on Neon (production); SQLite (dev/test).
